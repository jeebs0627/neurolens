Problem

“괜찮아요”라고 답한 아이와 동료의 시선과 마음은 괜찮지 않았습니다

자기보고만으로는 응답 왜곡, 과장, 부정 등 실제 상태를 놓치고, 발견한 뒤에도 케어로 이어지지 않습니다.

01

학생

시험·진로·관계 스트레스, 도움이 필요해도 말하기 어려워요.
  • 감정 변화를 인지하고 표현하기 어려움
  • 자기보고의 사회적 바람직성 응답 편향
  • 위험 신호를 스스로 축소해 보고
02

감정노동자

고객 응대 스트레스, 감정 소진 누적으로 계속 근무하기 힘들어요.
  • 감정 소진이 누적되지만 인지가 지연
  • 직무 특성상 감정 표현 억제와 위장
  • 성과 저하·이직 등 조직 손실로 연결
03

보호자 · 기업

상태 파악이 어렵고, 언제 개입하고 관리해야 할지 막막해요.
  • 눈에 보이는 문제가 되기 전까지 파악 곤란
  • 검사·선별 이후의 관리 체계 부재
  • 가정·학교·기업 간 정보·연계 단절
공통 문제 스스로 답한 결과가 실제 상태를 대변하지 못한 채 왜곡·과장되고, 위험이 발견되더라도 적절한 케어로 이어지지 않습니다.

그리고 선별된 뒤에도 — 결과지를 받은 아이에게 '내일 무엇을 어떻게 해야 하는지' 알려 주는 사람도, 후속 조치도 없었습니다.

산재사망을 증빙하는 과정에서 평소 혼자 고단했을 고인의 단서를 찾기 어려워 무력하다는 노무사의 하소연도 있었습니다.

발견 이후의 '케어 단절'이, 가능했던 회복의 시간을 놓치게 합니다. NeuroLens는 측정에서 케어까지 이어지는 AI Agent 폐루프를 만듭니다.

Two Tests + Daily Care

나를 알아가는 순간부터,
일상을 돌보는 습관까지, NeuroLens

NeuroLens는 웹캠과 스마트폰에서 얻는 시선·생체신호와 사용 환경 정보를 통해 자기 이해와 일상 케어를 연결합니다.

시선추적 AI로 설문과 시선 신호를 함께 분석해 나의 성향을 탐색하고, 자체 엔진 In_mind로 시선·심박 등 생체신호를 살펴 오늘의 컨디션을 돌아보도록 돕습니다. Eye·休는 스마트폰의 화면 자극과 주변 환경, 눈 반응과 사용 습관을 바탕으로 눈 사용 부담을 추정하고 케어로 안내합니다.

나의 특성을 이해하고, 오늘의 상태를 살피고, 일상에 필요한 쉼을 더합니다.

  1. 01

    캘리브레이션

    웹캠 품질·조도·얼굴 위치를 자동으로 점검하고, 시선을 보정합니다.

    5분 시선행동 측정

  3. 03

    AI 분석

    I-DT 기반으로 시선 특징 150+개를 추출하고, BMA 설명가능 모델로 개인별 Human Model을 만듭니다.

  4. 04

    리포트 · API

    개인별 프로파일을 리포트와 JSON API로 제공하며, 불확실성까지 함께 표시합니다.
