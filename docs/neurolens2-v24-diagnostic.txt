IN MIND 2.4 — 측정 및 검사 설계 개선 기록
2026-10-22

판단
현재 제품을 임상적으로 정확한 정서 진단이라고 부를 근거는 부족하다.
이번 변경은 관측 실패 원인과 과제 설계를 바로잡는 개발이며, 정확도를 입증한 임상 결과가 아니다.
기존 IN MIND 운영 검사와 연결하지 않으며 /neurolens2.html 관리자 환경에 한정한다.

실제 기록에서 확인한 문제
- 수치 프레임 5,162개, 관측 중앙 간격 약 33ms(약 30fps). 모든 구간에서 얼굴 관측·기본 자세 기준이 대체로 양호했다.
- 심박 채택 1/13창. 대부분의 탈락 원인은 ROI별 POS·CHROM 주기와 주파수의 합의 부족이었다.
- 얼굴이 잘 잡힌다는 안내만으로 심박 신호 확보를 보장할 수 없었다.
- 모든 구간을 12초씩 잘라 그림 변화·선택 과제 중의 RGB도 분석했다. 조명·표정·미세 움직임에 대한 안정 구간이 부족했다.
- 호흡 안내 기능만 존재했고, 실제 호흡수 측정 경로는 없었다.
- 그림 후 원 찾기는 버튼 방향 반응에 가깝고, 중립 대조·충분한 반복·개인별 신뢰도 없이 정서적 주의 해제로 해석할 수 없다.
- 보상 6회로 학습률·무쾌감·우울 상태를 신뢰성 있게 산출하기 어렵다.
- 시선 보정은 훈련 3점, 검증 2점의 평균 오차에 의존했다. 중앙 검증과 최대 지점 오차·흔들림 기준이 없었다.
- 빈 생체 지표와 수행하지 않은 과제 카드가 결과 의미를 흐렸다.

구현
1. 기본 3분: 시선 검증 28초 → 시작 상태 32초 → 그림 보기 48초 → 집중 32초 → 다시 쉬기 38초 → 마무리 2초.
   원 찾기·보상 선택을 신규 기본 검사에서 제거했다. 이전 기록은 그대로 읽는다.
   1분 모드는 시선을 측정하지 않고 준비 4초·자연 리듬 32초·집중 20초·마무리 4초로 구성한다.
   검사 시간은 실제 관측 예산이다. 체크인·환경 준비·연습·안내 시간은 별도이다.
2. 요청 영상 960×720 / 30fps. 얼굴 모델은 별도 640폭 영상에서 처리하고 RGB는 요청 해상도에서 추출한다.
   장치의 실제 지원 해상도와 프레임률을 기록한다. 이마·양 볼 영역을 확장하고 위치 변동을 완화했다.
3. v2.4의 심박은 일정한 화면 구간의 겹치지 않는 24초 창을 사용한다.
   1.6초 국소 정규화 POS·CHROM 계열 투영, CHROM 혼합 전 필터링, FIR 대역 필터, 실제 관측률·공백 검사를 사용한다.
   공간이 분리된 영역 2개 이상, 방법 합의, 주기성과 경쟁 주파수 검사, 배경 조명 검사, 앞뒤 12초의 독립 합의를 요구한다.
   같은 영상의 알고리즘·영역을 독립 센서로 세지 않는다. 채택 문턱을 낮춰 결과를 채우지 않았다.
   실시간 분석은 별도 작업자에서 수행하여 과제 표시 루프를 차단하지 않는다. 실제 후보만 파형으로 그린다.
4. 호흡 연구 경로: 얼굴 아래 고정 가슴 좌우 패치의 영상 기울기로 미세 수직 이동을 추적한다.
   평균 밝기 변화 보정, 질감·잔차 검사, 30초 이상 연속성, 4주기 이상, 좌우 주기 합의, 고개·배경 움직임 혼입 검사를 적용한다.
   8–30회/분의 연구 후보만 표시한다. 옷 질감·가슴 노출 범위·자세에 민감하며, 임상 기준 장비 대조는 미완료다.
   기존 기록에는 이 신호가 없으므로 과거 호흡값을 만들어 넣지 않는다. 호흡 안내의 속도는 측정값으로 쓰지 않는다.
5. 시선: 좌·우·중앙을 두 번 관찰하고 별도의 좌우·중앙 세 지점에서 검증한다.
   G2: 평균 오차≤12%, 최대 지점 오차≤18%, 흔들림≤10% / G1: 각각≤22%,≤28%,≤16%.
   화면 너비 대비 공학적 수평 오차이다. 기존 검사보다 정확하다는 비교 실험의 증거가 아니다.
6. 결과: 수행한 과제만 표시. 심박·호흡 각각 채택/보류, 관측 구간, 실제 후보 파형, 캡처 진단을 제공한다.
   단순 심박 복귀율을 자아탄력성·회복 능력 점수로 산출하지 않는다. 정서 점수는 체크인 출처를 유지한다.
   빠른 이동, 모바일 카드, 명확한 대비, 고정 밝기 측정 화면을 적용했다. 생체 측정 중 호흡을 유도하는 맥동 애니메이션을 쓰지 않는다.

검증과 남은 검증
- Node 75개: 신규 심박·호흡, 주파수 범위, 잡음·공백·저프레임·조명·움직임 거절, 보정 검증, 기록 호환·타이밍·점수·벤치마크.
- Python 13개: 관리자 인증, 로컬 티켓, 경로 격리 등.
- 기존 운영 파일 438개·기존 자산 무결성 확인. 유료 인프라와 서버 함수 추가 없음.
- 실제 기존 기록의 신호를 새 투영으로 재생했을 때, 동일 12초 구간에서 채택은 여전히 1/13이었다.
  이 사실은 소프트웨어만 바꿔 과거 저신호 기록을 복구하지 못했음을 뜻한다. 개선된 수집·새 24초 프로토콜의 효과를 입증하지 않는다.
- 합성 파형 성공을 사람의 정확도 수치로 보고하지 않는다. 이전 원본 기록과 점수는 변경하지 않았다.
- 일반 Chrome 연결이 검증 중 끊겼다. 앱 내 브라우저는 1fps로 측정 전 차단됐다. 차단 조건을 우회하지 않았다.
- 새 전체 절차의 실제 웹캠 성공률과 기준 장비 정확도는 아직 미확인이다.

바로 다음 실측에서 볼 항목
같은 카메라·정면 조명에서 v2.4 3분 검사. 표시·카메라 실제 fps, ROI 면적·관측률, 심박 채택/탈락 이유,
가슴 추적 범위·질감·호흡 후보, 시선 검증 3지점과 중앙 드리프트를 원자료와 함께 확인한다.
피험자별 다른 날 반복과 손쉬운 독립 심박 참조(가능한 장치 확보 후)를 추가해야 정확도·반복성을 평가할 수 있다.
사용자 편의성과 반복성이 입증되기 전, 짧은 과제를 여러 개 더 붙이거나 정서 진단 점수를 합성하지 않는다.
