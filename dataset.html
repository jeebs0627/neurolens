지표의 해석

완료율은 불러온 동의 세션의 완료 비율입니다. 정확도는 기준 장비·동기화 근거를 확인한 세션에서 별도로 계산합니다. 코드 변경·프롬프트 수·배포 성공은 정확도 향상이나 특허성의 증거가 아닙니다.

관측 → 문제 정의 → 코드 변경 → 독립 검증의 연결을 축적합니다. 원시 측정과 개인 메모는 공개 GitHub 이력에 전송하지 않습니다.
